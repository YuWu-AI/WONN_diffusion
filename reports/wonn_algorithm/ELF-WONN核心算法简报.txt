ELF-WONN 核心算法简报
聚焦当前 ELF-WONN 实现中振荡器 backbone 的状态、耦合动力学与读出过程。



技术摘要
ELF-WONN 用 Winfree 振荡器动力学完整替换 ELF 的 Transformer denoiser backbone，但不改变 ELF 的连续
latent、Flow Matching 或采样接口。每次 denoiser 前向都会把当前 token hidden state 确定性地初始化为相位 θ 与内在
频率 ω；相位在 attentive Winfree coupling 下快速演化，频率只在相邻层之间慢速更新，最终仅从相位的周期特征 [sin
θ, cos θ] 读出结果。

正式 ELF-WONN-B 为：每个 token 384 个振荡器、12 个 coupling heads、6 层 × 每层 2 个 inner steps，因此每次前向
进行 12 次 coupling evaluation；层间共有 5 次 frequency transition。

1. 状态表示与确定性初始化
对 batch 中第 i 个 token，WONN 的内部状态为


  θ_i, ω_i ∈ R^K,     K = 384
  P(θ_i) = [sin θ_i, cos θ_i] ∈ R^(2K)


ELF 的输入、时间 token、self-conditioning/CFG token 和 mode token 先按原接口组成 hidden sequence H。归一化后，
用两个投影初始化：


  (a_i,k, b_i,k) = W_θ H_i
  θ_i,k^0 = atan2(b_i,k, a_i,k)
  ω_i^0 = W_ω H_i


每个 (a,b) 对会先单位化，再用 atan2 得到相位。初始化不引入随机数；下一次 flow/sampling step 会从新的当前
latent 重新计算 (θ,ω)，不会跨 denoiser 调用携带隐藏状态。

整体路径： ELF hidden H → (θ⁰,ω⁰) → L 个 WONN layers → final phase features → ELF-compatible
output。

2. Attentive Winfree 单步动力学
384 个振荡器被分成 12 组，每个 head 管理 32 个通道。对第 l 层、第 s 个 inner step，先从周期特征计算带 RoPE 的
query/key：
  A_i,j,h = softmax_j( q_i,h · k_j,h / sqrt(d_qk) )



注意力 A 只表示 token 间的耦合权重。每个 head 再从相位产生接收端敏感度 S 和发送端影响 I：


  S_i,h = tanh(W_h^S [sin θ_i,h, cos θ_i,h] + b_h^S)
  I_j,h = tanh(W_h^I [sin θ_j,h, cos θ_j,h] + b_h^I)
  m_i,h = Σ_j A_i,j,h I_j,h
  v_i,h = ω_i,h + S_i,h ⊙ m_i,h


最后用有界、可学习步长推进相位：


  γ_l = γ_max · sigmoid(r_l),      γ_l 初值 0.1，γ_max = 0.25
  θ_i,h ← wrap(θ_i,h + γ_l v_i,h),     wrap 范围为 [-π, π]



padding mask 直接作用在 A 上。这里没有 Transformer 的 value projection residual，也没有 FFN；attention 只参数化
Winfree coupling，真正改变状态的是上面的相位方程。

3. 快相位、慢频率与 phase-only 读出
一个 WONN layer 内，ω 在 2 个 inner steps 中保持不变；完成相位迭代后，仅在还存在下一层时执行 gated residual
frequency transition：


  δω^l = tanh(W_ω^l RMSNorm([sin θ^l, cos θ^l, ω^l]))
  ω^(l+1) = ω^l + tanh(g_l) · δω^l
  θ^(l+1,0) = θ^(l,T)


g_l 从 0 初始化，因此模型训练初期近似固定内在频率，之后再学习跨层的慢速变化。相位在层边界直接传递，不经过
额外坐标变换。最后一层之后不再更新 ω，因为输出只读取最终相位：


  H_out = [sin θ^(L,T), cos θ^(L,T)]
  y_continuous = FinalLayer(H_out)
  y_decode = Unembed(GELU(H_out W_proj + b_proj))       # 仅 decode mode


控制 token 在动力学中参与耦合，但读出前会被移除；返回的 continuous output 与 decoder logits 仍保持 ELF 原有
shape 和 dtype 契约。

4. 精简伪代码

  H, mask, n_ctrl = PrepareELFSequence(x, t, self_cond, mode)
  θ, ω = DeterministicInit(H)


  for l = 1 ... L:
       for s = 1 ... T:
            A = MaskedAttention(P(θ), RoPE)
            message = A @ Influence(P(θ))
            velocity = ω + Sensitivity(P(θ)) * message
            θ = wrap(θ + step_l * velocity)


       if l < L:
            ω = ω + gated_frequency_delta(P(θ), ω)

  H_out = P(θ)[:, n_ctrl:]
  return ContinuousHead(H_out), OptionalDecodeHead(H_out)

5. 汇报时必须明确的边界
       定位： WONN 是 denoiser backbone，不是新的 latent space；θ/ω 只存在于一次前向内部。
       机制： attention 只产生耦合权重，没有标准 A·V residual 或 FFN。
       核心归纳偏置： θ 每个 inner step 更新，ω 只在层间更新，最终仅从相位读出。
       比较边界： 12 次 coupling evaluation 只是结构次数对齐，不能直接推出 FLOPs、延迟或任务质量更优。
